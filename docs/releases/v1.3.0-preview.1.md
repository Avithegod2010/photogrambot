PhotogramBot 1.3.0 (preview, versionCode 5)

The calm-interface release. Everything here is visual and accessibility work:
backup, sync, encryption, remote control and the database are untouched.

What changed
- One design system: a closed type scale (10/11/12/13/15/17/20/24/30), 4-based
  spacing, five corner radii, a 120/180/240 ms motion scale, a 48 dp touch target
  and one status vocabulary (local / queued / uploading / backed up / failed /
  restored / duplicate).
- 27 accessible primitives replace hand-rolled rows, cards, sheets and dialogs.
  Every control has a role, a label where needed, and a state.
- Gallery: photo-first chrome, a measured sticky date header, a collapsed
  library overview (tap to expand the numbers and the 6-month chart), an upload
  progress bar, a selection bar with an overflow sheet, and a proper trash dialog.
- Collections: responsive 2/3/4-column cover grid, bottom-sheet album/trip/saved
  search menus, trash selection with dialog confirmations.
- Settings: a search field that jumps to the matching section; bot reset and
  SQLCipher encryption now confirm in dialogs instead of system alerts.
- Setup and Lock rebuilt visually without changing setup, PIN, decoy or backoff
  logic. Upload queue rebuilt as a trust surface with a three-stat summary.
- Every screen uses the same app bar, empty state and responsive grid. No
  Dimensions.get remains.
- Accessibility: TalkBack labels/states throughout, live regions for progress and
  errors, reduced-motion support, Arabic RTL mirroring, and a static UI guard
  that fails the build on raw hex colours or off-scale type.
- New recovery screen if a render ever fails ("your archive is safe").

Install notes
- This APK was re-signed with the local debug keystore so it installs in place
  over the current dev build; the SQLite index and SecureStore survive.
- It is a preview/dev-client build: it still needs Metro on port 8081 (or 8082)
  for JS, exactly like the previous previews.
- 78 system alerts remain, all informational or OS-level except a few
  multi-choice confirmations still queued for migration.
- Full device verification (TalkBack walk, 200% font, light/AMOLED, accents,
  Arabic RTL, Maestro smoke) is still owed.

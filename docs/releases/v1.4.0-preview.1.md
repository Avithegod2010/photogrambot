PhotogramBot 1.4.0 (preview, versionCode 6)

The Material You motion and haptics release. Backup, sync, encryption, database
and remote-control logic are untouched.

What changed
- Material 3 navigation bar: an animated 32 dp indicator pill behind the active
  tab icon, with the gesture inset reserved so labels never collide with the
  system pill.
- Material 3 controls: the switch slides its thumb and shows a check mark when
  on; selected segments grow slightly and gain a check; filter chips show a
  check; dialogs and sheets use 28 dp corners and dialogs scale in.
- Ripples on every pressable in every theme, including dynamic colour. They are
  clipped to the control's rounded outline.
- Haptics: selection ticks for tabs, segments, chips, switches and the PIN
  keypad; light impacts for actions; medium for long-press and destructive
  confirms; success/error for outcomes. New Settings -> Appearance -> Haptic
  feedback toggle, on by default.
- Motion: progress bars animate their fill, the gallery selection bar slides in,
  and the library overview chevron rotates. All 120-240 ms, transform/opacity
  only, disabled under reduced motion.
- Under the hood: expo-haptics 57.0.3, a lazy fail-soft haptics layer, and a
  haptics preference that existing installs inherit as enabled.

Install notes
- This APK is re-signed with the local debug keystore so it installs in place
  over the current dev build; the SQLite index and SecureStore survive.
- It is a preview/dev-client build. If Metro is running it will load JS from
  there; otherwise it uses the embedded bundle.
- Haptics require this native build. Older APKs stay silent by design.
- Full device verification (TalkBack walk, 200% font, light/AMOLED, accents,
  Arabic RTL, Maestro smoke) is still owed.

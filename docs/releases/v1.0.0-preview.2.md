PhotogramBot 1.0.0 (preview, versionCode 2)

First installable APK since the device-verification work began. Install it over an
older build with `adb install -r`, or let the in-app updater (Settings -> About)
fetch it — note the preview APK is signed by EAS's managed keystore, so a build
signed with your own keystore must be uninstalled first.

Fixes in this build
- Share target: the manifest shipped doubled intent-filter names
  (android.intent.action.android.intent.action.SEND), so the app never appeared
  in the Android share sheet. Filters are now generated correctly.
- Near-duplicate guard no longer re-enqueues the same photo on every scan, and
  turning the guard off now releases photos it had already skipped.
- Backup restore carries photos.ocr_text and photos.motion_checked (screenshot
  search text and the motion-backfill markers used to be dropped), clears the
  stale upload queue / embedding index on a replace-restore, and no longer
  imports per-device kv state such as the remote /pause flag.
- Photo version history, encrypted backups, weekly digest and the filter sheet
  were exercised on hardware for the first time.

Known limits (unchanged)
- Bot API downloads cap at 20 MB; larger originals must be saved via Telegram.
- Video backup is beta (19 MB parts).
- The iOS target is untested.

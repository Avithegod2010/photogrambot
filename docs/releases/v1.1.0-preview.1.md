PhotogramBot 1.1.0 (preview, versionCode 3)

The customisation release: 21 appearance and layout controls, most under
Settings -> Appearance. This build also contains the R37 fixes (share-target
manifest, near-duplicate re-enqueue loop, backup restore columns).

Highlights
- Theme: Dark / AMOLED / Light / Auto, an accent-colour picker (8 presets or a
  custom hex), and an optional scheduled dark-at-night switch.
- Gallery: 2-5 columns, square or natural aspect, compact gaps, per-badge
  toggles, photo counts under each date header, and a draggable date scrubber.
- Per-album accent colours and cover curation (long-press -> Set as cover,
  reset to newest from the album style dialog).
- Viewer: auto-hiding controls (2/3/5/8 s) and a compact/detailed info sheet.
- Text: four font scales and four date formats.
- Branding: custom in-app name, Default/Accent/Monochrome launcher icons,
  accent splash.
- Widget: date overlay and compact layout (auto-compact at small sizes).
- Notifications: accent colour.
- Captions: choose and reorder the metadata lines written to the channel (the
  content hash is always kept).

Install notes
- The preview APK is signed by EAS's managed keystore. A debug-signed dev
  client must be uninstalled first (that wipes the local SQLite index; restore
  it from the channel's pinned database backup).
- App-icon switching uses three launcher activity-aliases; if the launcher
  keeps the old icon after a change, close and reopen the launcher.

Known limits (unchanged)
- Bot API downloads cap at 20 MB; larger originals must be saved via Telegram.
- Video backup is beta (19 MB parts).
- The iOS target is untested.
- Nothing in this build has been device-verified yet.
